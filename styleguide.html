Typography Color Spacing & Grouping Components Guidelines

01 — Foundations

Typography

Base: 16px body. Every level below is a Major Third (×1.25) step. Floor: nothing renders below 12px, anywhere.

Level Specimen Class Size (mobile → md) Weight Use for
Title Aa .heading-title 28 → 44px 700 Homepage hero only — one per site, not per page.
H1 Aa .heading-1 28 → 36px 700 Inner-page title. One per page.
H2 Aa .heading-2 20 → 26px 600 Section headers. Repeats up to 5× — stays lighter than H1 on purpose.
H3 Aa .heading-3 18 → 20px 500 Subheads under H1/Title, or small in-page headings.
Body Aa unset (base) 16px 400 Default paragraph text — the root of the scale.
Meta Aa text-sm 14px 400–500 Nav links, page-intro lines, buttons, card copy.
Eyebrow Aa .text-eyebrow 13px 700 Category labels near a heading. Uppercase, 0.06em tracking. Never a CTA.

02 — Foundations

Color

Two near-blacks, full stop. Need a third gray? Reuse Ink or Muted instead — #212529, #333, and rgb(90,96,102) were all collapsed into these.

Swatch Token Hex Use for
Ink #1e1e1e Headings, body text, nav, buttons. The one primary black.
Muted #7a7570 Subtitles, eyebrows, intro lines, footer meta. Never on CTAs.
Accent #FD6F00 Hover states, active nav link, name highlight.
Section ground #f8f7f1 Alternating section background.
Page ground #ffffff Default page background, card surfaces.

03 — Foundations

Spacing & Grouping

Pattern Value When
Tight grouping ~8px Heading + the line directly supporting it (subtitle, intro para). Signals "one idea."
Eyebrow + heading 8px Eyebrow sitting directly above its H2. Wrap both in their own tight group so they read as one unit, separate from the wider gap before the body content below.
Section gap 16 / 32 / 64px Scale the gap to how related the two sections are. 16px for closely related groups (e.g. a card row directly under its intro). 32px for a genuinely new group within the same page area. 64px between distinct top-level sections of a page.
Same-tone distance widen the gap Two same-color elements (e.g. H2 + button) 8px apart still read as cramped. Fix with space, not size.
Container spacing padding-64-64 + gap-64 Top-level section container: pt-16 pb-16 for the outer edges, gap-16 between sections. Spacing lives in one place, not split across the container and each section — sections carry no vertical padding of their own.

04 — Components

Components

Component Example Rule
Eyebrow label Analytics .text-eyebrow + Muted color. Clickable? It's not an eyebrow — it's a button.
Button / CTA Take a Look Always Ink, never Muted. Cramped against a heading? Fix with spacing, not color.

05 — Rules of thumb

Guidelines

Size + weight = hierarchy Title/H1 = 700, H2 = 600, H3 = 500. Don't flatten weight even when size differs.
Muted ≠ actionable Muted recedes. Buttons and CTAs stay Ink, always.
12px floor No exceptions — tooltips and hover text included.
Two grays only Reuse Ink or Muted before adding a third.
Group tight, break wide ~8px = "these belong together." 24px+ = "new group."
